EXP IP Scanner 1.1.3

Copy the IP list you actually need.

Version 1.1.3 adds Copy IPs: select a few devices, filter the table, or use the whole visible result set and copy only their IP addresses, one per line.

Built for the next step in the workflow

Consultants often scan the network and immediately need the addresses somewhere else: a PowerShell command, firewall rule, ticket, spreadsheet, vendor utility, or another diagnostic tool. Copy IPs removes the cleanup step from the existing full-row copy.

Selection and filters still mean what they should

If devices are selected, Copy IPs uses only that selection. If nothing is selected, it copies every row currently shown after search and filters are applied. The output is a plain one-address-per-line list with no headers or extra columns.

The update channel remains EXP-owned

As with 1.1.2, update checks, downloads, release links, and the future signed updater feed continue to use nazar-exp/EXP-IP-Scanner as the permanent product authority.
