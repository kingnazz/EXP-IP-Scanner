EXP IP Scanner 1.4.4

Cleaner default scans on networks that intercept DNS.

Version 1.4.4 removes TCP port 53 from the default service sweep. Some gateways transparently proxy or intercept DNS and accept a TCP connection for every address in the subnet, which can make unrelated devices look like they are running DNS.

DNS is no longer probed by default

The normal scan now checks 33 consultant-focused TCP ports without port 53, preventing gateway-level DNS behavior from creating misleading DNS service chips across the results table.

Custom DNS scans still work

DNS remains in the service catalog. If you explicitly include TCP 53 in a custom port list, EXP IP Scanner will scan it and identify it normally.

No other default services were removed

RDP, SMB, SSH, web management, printers, databases, Synology DSM, WinRM, SIP, and the other existing consultant-focused defaults remain unchanged.

Why this is a patch release

This is a targeted accuracy fix. It changes the default port selection only and does not alter vulnerability checks, device actions, update behavior, or stored scan data.
