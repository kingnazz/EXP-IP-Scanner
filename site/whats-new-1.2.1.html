EXP IP Scanner 1.2.1

Built for ScreenConnect Backstage.

A dedicated console companion now gives consultants the same core network discovery from Backstage without depending on a normal Windows desktop or WebView2.

A Backstage-native workflow

The new EXP IP Scanner Backstage.exe runs directly from PowerShell or Command Prompt. It auto-detects the recommended local subnet, streams discoveries while the scan runs, then prints a clean device table.

The same scanner engine

This is not a second scanner implementation. The console companion uses the same Rust discovery engine as the desktop application, including hostname resolution, MAC and manufacturer lookup, latency, and open-service detection.

No WebView2 requirement

The Backstage executable does not initialize a Tauri window or WebView. That makes it suitable for ScreenConnect Backstage and other limited remote shells where normal GUI applications are unreliable.

Useful from scripts too

Use --target for a specific subnet, --ports for a custom service set, --no-services for a lighter discovery pass, --csv for a ticket-ready export, or --json for automation.

Two easy ways to get it

The Backstage companion is published as its own standalone release asset and is also included beside the normal GUI inside the portable ZIP.
