EXP IP Scanner 1.1.2

EXP now owns the update channel.

Version 1.1.2 moves the app’s update checks, downloads, release links and future signed updater feed to the EXP-owned GitHub repository.

The update source belongs to EXP

The installed edition now checks nazar-exp/EXP-IP-Scanner for the latest stable release. The same company-owned repository is also the target for the signed Tauri updater feed when in-app signing is enabled.

Downloads and links follow the same authority

Website, Releases, Downloads and Privacy links now open the EXP-owned GitHub Pages site and repository, so consultants are not sent through a personal account to find the product.

The development workflow stays simple

Development can continue from the existing source repository. Automation mirrors the exact code, tags, release notes, installer, portable ZIP and checksums into the EXP-owned repository, so both copies distribute the same release artifacts.

Upgrade path from 1.1.1 Version 1.1.1 still checks the previous personal release channel, which will publish and mirror 1.1.2. Once 1.1.2 is installed, all later update checks use the EXP-owned repository.
