EXP IP Scanner 1.1.2

Updates now belong to the EXP-owned repository.

Version 1.1.2 moves the app’s update checks, download links and product website authority from the personal development mirror to nazar-exp/EXP-IP-Scanner.

The app now checks EXP directly

When you press Check now, the installed edition asks the EXP-owned GitHub Releases feed which stable version is current. The Tauri updater endpoint points there too.

Downloads and product links follow the same authority

About, the website, release buttons and privacy links now use the EXP-owned repository and GitHub Pages site, so technicians are not dependent on a personal GitHub account for future releases.

No change to scan behavior or privacy

Scanning, storage and network behavior are unchanged. Update checking still happens only when you ask, and the portable edition still contains no updater.

For anyone on 1.1.1 Version 1.1.1 still checks the old development mirror, which receives the same releases, so it can discover 1.1.2 normally. Once 1.1.2 is installed, future checks use EXP-owned releases directly.
