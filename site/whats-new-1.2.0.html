EXP IP Scanner 1.2.0

Copy the whole network context in one click.

The network summary now has a single copy action that turns the adapter, local IP, gateway, scan range and public IP into a clean block ready for a ticket or work note.

Built for the next thing a technician actually does

After identifying the network, the next step is often documenting it. Instead of clicking and pasting each value separately, one button now copies the full network context in a readable format.

Useful even when a value is missing

No default route, a disabled public-IP lookup, a failed lookup, or a machine with no detected adapter is written plainly in the copied summary. The block stays understandable without inventing data or dropping fields.

Still intentionally lightweight

The feature adds no background process, storage, telemetry, network request, or dependency. Individual values in the summary still copy on click exactly as before.
