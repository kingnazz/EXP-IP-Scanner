EXP IP Scanner 1.2.0

Copy the network context, not five separate fields.

The network strip can now copy the facts you usually need in a ticket or handoff as one clean block.

One click, five useful facts

A new copy button at the right side of the network summary copies the adapter, local IP, default gateway, scan range with address count, and public IP together. Individual IP and gateway values are still clickable when you only need one field.

Ticket-ready even when a value is missing

The copied block says None, Unavailable, Off, or Not detected where appropriate instead of silently dropping the field, so a pasted network snapshot stays unambiguous.

Small polish for the four-probe Ping

The Ping action tooltip now matches the diagnostic introduced in 1.1.7: it sends four probes and reports loss and latency statistics rather than describing the action as a single ping.

No extra network traffic or stored data

This clipboard feature is local. It adds no network request, telemetry, scan history, permission, or background process. Portable and installed editions behave the same for this feature.
