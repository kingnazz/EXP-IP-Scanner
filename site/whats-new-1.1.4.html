EXP IP Scanner 1.1.4

Updates can stay inside the app.

Version 1.1.4 establishes EXP IP Scanner’s signed update channel. Install this release once, and later installer releases can be downloaded, verified, installed, and relaunched directly from About.

Install and restart

The installed edition now carries EXP’s Tauri updater public key. When a newer signed release is available, the update check can verify it and offer Install and restart instead of sending you to the browser.

Signed before anything runs

Future updater installers are signed during the release build and described by a signed latest.json feed in the EXP-owned repository. If release signing is not configured correctly, publishing stops instead of producing an updater package installed copies cannot trust.

One manual bridge install

Versions 1.1.3 and earlier were built before the signing public key existed, so they cannot trust the new updater feed yet. Install 1.1.4 manually once. After that, later updates can use the in-app path.

Portable stays portable

The portable ZIP still contains no updater and never installs itself. That edition remains a self-contained technician tool you replace manually when you want a newer build.
