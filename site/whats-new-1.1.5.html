EXP IP Scanner 1.1.5

Updates are easier to notice.

The installed edition now checks quietly after startup and surfaces a compact update indicator in the top bar when a newer signed release is ready.

No need to remember to check

Shortly after startup, the installed edition asks the EXP-owned release feed whether a newer stable version exists. If there is nothing new, the app stays exactly as it was.

A small signal, not a popup

When an update is available, the top bar shows a compact Update vX.Y.Z badge with an attention icon. It does not interrupt scanning or open a modal on its own.

One click to the updater

Clicking the update badge opens About with the update result already loaded. Signed releases can go straight to Install and restart without making you run the same check twice.

Portable stays manual

The portable edition still performs no update check and contains no self-updater. Replace its ZIP manually when you want a newer build.
