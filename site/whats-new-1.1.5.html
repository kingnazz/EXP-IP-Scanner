EXP IP Scanner 1.1.5

Updates now tell you when they are ready.

The installed edition quietly checks once after launch. If a newer signed release exists, a compact Update available indicator appears at the top of the app.

No more hunting through About

When the app is current, nothing changes. When an update exists, the title bar shows a small red alert with the available version. It stays visible without interrupting a scan.

One click to the installer

Click the update indicator and About opens with the known release already loaded. Signed releases can go straight to Install and restart without running a second update check.

Quiet when the network is not

The startup check is advisory. If GitHub is temporarily unreachable, launch continues normally and no error toast appears. The manual Check now button still reports errors when you explicitly ask for a check.

Portable stays unchanged

The portable build still contains no updater and makes no update checks. Replace the ZIP manually when you want a newer portable version.
