EXP IP Scanner 1.1.6

Useful row actions are easier to discover.

The results area now tells you about the interactions that were already there instead of expecting you to stumble into them.

Double-click for the full device view

A subtle hint in the results toolbar now points out that double-clicking a device opens its details drawer. That panel includes everything found during the scan plus the device actions available for that host.

Right-click for quick actions

The same hint calls out the existing right-click menu for Remote Desktop, file shares, SSH, web interfaces, ping, traceroute, and copy actions where they apply.

The hint stays out of the way

When the results area gets narrow, including while the details drawer is open, the toolbar hint hides automatically. Every device row still carries the interaction reminder as a hover tooltip.

Small tooltip cleanup

The search-clear icon now has an explicit tooltip too, keeping icon-only controls consistent with the rest of the interface.
