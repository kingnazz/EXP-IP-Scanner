1.0.0

First release
  • Automatic detection of the network you are on, with the target already filled in. Adapter ranking prefers a wired or wireless NIC over a Hyper-V switch, a Docker bridge or a VPN tunnel, and every adapter stays selectable.
  • Device discovery over ICMP, TCP and the ARP cache, with a second ARP pass so a device that was slow or lossy on the first sweep does not disappear between scans. No administrator rights needed.
  • Hostname resolution, MAC addresses and manufacturer names from the full embedded IEEE registry, all resolved without a network connection of their own.
  • Detection of 32 services that matter on a business network, shown with their names rather than as bare port numbers.
  • Remote Desktop, file share, SSH, VNC and web-interface shortcuts, plus ping and traceroute, enabled only where a device’s open ports support them.
  • Results table with numeric address sorting, resizable and optional columns, instant search across every field, multi-select and a right-click menu.
  • CSV export that opens cleanly in Excel, and tab-separated copy for tickets.
  • Light and dark themes, following Windows by default.
  • A portable edition that needs no installation and never writes to the folder it was extracted into, and an installer edition that can check GitHub for updates.

A lightweight network discovery tool built for everyday technician workflows.
