Install updates without leaving the app

The installed edition now carries EXP's updater signing key. Signed future releases can be verified, installed, and relaunched directly from About with Install and restart.

A new Copy IPs action copies the selected devices, or every device currently shown, as a clean one-address-per-line list ready for scripts, firewall rules, tickets, and other network tools.
