EXP IP Scanner 1.1.0

The network you are standing on, in one line.

Version 1.1.0 adds a network summary to the top of the window. Before a scan starts it already tells you which adapter you are on, this machine’s address, the default gateway, what is about to be swept, and the public IP address the site appears as from outside. It is also the release where EXP IP Scanner starts looking like an EXP product.

Everything a site visit starts with

The summary sits under the scan bar and stays on screen while you work. Adapter, local IP, gateway, scan range and public IP, on one 28-pixel line. Click any address to copy it, because the next thing you do with a gateway address is paste it into a ticket, a browser or an SSH session.

The gateway, from the routing table

The default gateway is read from the routing table and matched to the adapter its route actually leaves by. On a laptop with a VPN up, the tunnel shows the tunnel’s gateway and the wired NIC shows the office one. An adapter with no default route — a second NIC, a Hyper-V switch — says so plainly instead of being given an invented x.x.x.1.

Your public IP, without opening a browser

Checking what address a customer site presents to the internet used to mean leaving the tool. Now it is already there. The lookup runs in the background and never delays startup, falls back to a second service if the first is unreachable, and reports “Unavailable” rather than failing loudly when neither answers. A refresh button asks again whenever you want.

It is still the only thing that leaves your machine

The lookup asks a plain-text service what address you appear as. It sends no scan results, discovered-device data or application identifier; like any HTTPS request, the lookup service can see the public IP making the request. It is named in the application’s Content-Security-Policy, so the window cannot reach anywhere else, and it can be switched off in Settings, where the services it uses are named. Scan results are still never uploaded, and there is still no account, telemetry or analytics of any kind.

EXP branding throughout

The EXP IP Scanner logo now appears in the title bar and in About, the accent colour across the interface is the EXP orange this website already used, and the application, executable, installer, window and site icons are all derived from the same artwork rather than drawn separately.

Still deliberately not included No inventory database, no historical scan tracking, no monitoring, no vulnerability scanning, and no cloud account. Results live in the current session unless you export them.
