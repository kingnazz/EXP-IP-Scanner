EXP IP Scanner 1.0.0

Fast network discovery without the platform overhead.

Version 1.0.0 is the first production release of EXP IP Scanner. It is built for the everyday moment when a technician needs to know what is on a network, identify the device, and connect to it without opening three different utilities.

Start on the right network

The scanner detects the active subnet at launch and fills the target automatically. Physical Ethernet, Wi-Fi, and USB adapters are preferred over virtual switches and tunnels, while every detected adapter remains available when you need to choose manually.

Find devices while the scan is still running

Discovery combines ICMP, TCP probing, and the ARP cache instead of relying on ping alone. Results stream into the table as devices are found, and hostname resolution runs alongside the sweep so useful names appear without waiting for the scan to finish.

See the details that help you recognize the device

Each result can include the IP address, hostname, MAC address, manufacturer, latency, and common open services. Manufacturer lookup uses an embedded IEEE registry, so it does not need an external lookup service.

Go straight from discovery to action

When the scan finds a service that supports it, EXP IP Scanner can open Remote Desktop, file shares, SSH, VNC, or the device web interface. Ping and traceroute are available for quick follow-up troubleshooting.

A results table built for technician workflows

Version 1.0.0 includes numeric IP sorting, resizable and optional columns, search across every device field, filters, multi-select, keyboard navigation, a right-click menu, CSV export, and tab-separated copy for tickets or spreadsheets.

Portable and installed editions

The portable edition is built for field use. Extract it and run it without installation, and it contains no updater code. The installed edition adds a normal Start Menu entry and can check GitHub for a newer version when you ask.

Deliberately not included No inventory database, no historical scan tracking, no monitoring, no vulnerability scanning, and no cloud account. Results live in the current session unless you export them.
