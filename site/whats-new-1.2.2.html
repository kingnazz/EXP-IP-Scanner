EXP IP Scanner 1.2.2

Two editions. Fewer moving parts.

The experimental Backstage companion has been retired. EXP IP Scanner is back to the two editions that work best in everyday use: Portable and Installer.

Portable is simple again

The portable ZIP now contains only the normal EXP IP Scanner executable and its README. No second console executable is bundled beside it.

Installer stays the everyday workstation option

The installer remains the same standard Windows app with Start Menu integration and signed in-app update support.

Why the Backstage build was retired

Real-world testing showed inconsistent behavior in remote-shell environments and avoidable antivirus friction. Rather than carry a third edition that is less predictable, the project is focusing on the two supported desktop editions.

No scanner behavior changed

Network discovery, hostname and vendor resolution, service detection, export, device actions, privacy behavior, and the normal desktop interface are unchanged in 1.2.2.
